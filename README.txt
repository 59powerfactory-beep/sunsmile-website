sun smile 公式ホームページ（試作版）

1. index.html をブラウザで開くとサイトを確認できます。
2. 「ブログを管理」から記事の新規作成・編集・削除ができます。
3. 記事はブラウザの localStorage に保存されます。別端末には同期されません。
4. 「記事をJSONで書き出す」でバックアップし、読み込みで復元できます。
5. サイト公開には Netlify、GitHub Pages などへのアップロードが必要です。
6. 公開後に管理画面から投稿して全閲覧者に反映するには、WordPress / microCMS / Decap CMS 等のCMSと認証・サーバー側保存の導入が必要です。この試作版はその機能をまだ搭載していません。
7. メールアドレス・メニュー・文章は公開前に確認してください。メニュー画像は仮の絵文字です。
8. ロゴの元画像は assets/sun-smile-logo.jpg に同梱しています（現状は未配置）。
